# Quick Start Guide

Run full Electron desktop app:

```sh
npm run dev
```

Run standalone backend & static servers (:3001, :3002, :3003):

```sh
node dev-server.js
```

Truncate and reset database to clean install state:

```sh
npm run db:truncate
```

Build the Windows installer (`release/Kahera-Setup.exe`):

```sh
npm run build:win
```
